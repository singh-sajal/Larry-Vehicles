# Demo vehicle media

These files are downloaded exterior 360° spins used only by the local demo data.

| Demo vehicle | Folder | Source |
| --- | --- | --- |
| 2022 Toyota Fortuner ZX | `fortuner/360` | `https://stimg.cardekho.com/images/feelthecar360view/Exterior/Toyota/Toyota-Fortuner/1616818166/Exterior.html` |
| 2021 Toyota Glanza VXi | `glanza/360` | `https://stimg.cardekho.com/images/feelthecar360view/Exterior/Toyota/Toyota-Glanza/56324558/Exterior.html` |

Each folder contains 36 studio frames (`frame-01.jpg` ... `frame-36.jpg`, 930 × 620).
`RealVehicleMediaSeeder` attaches six frames to the gallery and all 36 to the `360-frames`
collection. The images are third-party assets included for local development/testing only.
Replace them with photography you own or have licensed before deploying the demo publicly.
